# ASTERYON Editor Unificado v2.1

Melhorias desta versão:
- painéis laterais redimensionáveis e largura persistida localmente;
- abas laterais com largura mínima e rolagem horizontal para não sobrepor textos;
- nova aba Modelos;
- quatro modelos originais inspirados em padrões de varejo, atacado B2B, distribuidora institucional e catálogo B2B por marcas;
- página contínua com altura automática conforme os objetos avançam para baixo;
- linhas de dobra para visualizar a sequência da página longa;
- resoluções rápidas por dispositivo: Desktop 1366/1440/1920, Tablet 768/834, Mobile 360/390/430;
- padrão Tablet atualizado para 834 px;
- modelos continuam editáveis com objetos atômicos, camadas, grupos e liberdade de reposicionamento.

Os modelos reproduzem padrões funcionais comuns observados em referências públicas, mas não copiam marcas, logotipos, textos, imagens ou identidade proprietária dos sites usados como referência.
