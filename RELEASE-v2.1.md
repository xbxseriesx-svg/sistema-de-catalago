# ASTERYON Catálogo Digital v2.1

Versão aprovada do editor visual com base unificada Bolt + Canvas Studio + Lovable.

Principais recursos desta versão:
- página contínua com rolagem longa;
- painéis laterais redimensionáveis;
- presets Desktop, Tablet e Mobile;
- biblioteca de modelos pré-criados;
- editor visual livre com elementos, camadas, catálogo e histórico;
- modelos Varejo Contínuo, Atacado B2B, Distribuidora Institucional e Catálogo de Marcas B2B.

Build Windows 11 x64 validado via GitHub Actions em 2026-08-13.
